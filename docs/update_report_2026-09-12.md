### 可直接使用的類別

| 類型 | API 代碼 | 用途 |
| --- | --- | --- |
| 葉綠素影像 | `OLNT_S3_CHL`、`Sentinel2_CHL`、`GOCI_CHL` | 葉綠素 a 異常與藻華/優養化判讀 |
| 懸浮物影像 | `OLNT_S3_TSM`、`Sentinel2_TSM`、`GOCI_TSS` | 懸浮固體、河口泥沙羽流與港區擾動判讀 |
| 自然色圖磚 | `GOCI`、`OLNT_S3` | 事件當日影像背景與雲遮判斷 |
| 海溫影像 | `SLNT_S3_SST` | 海溫、水團邊界與生態壓力判讀 |
| 觀測站 metadata | `CWA`、`IHMT`、`WRA`、`NAMR` | 建立風、流、潮、浪測站資料表 |

### 需申請或確認的資料

| 資料/API | 狀態 | 建議處理 |
| --- | --- | --- |
| `EPA/MWQ` | NODASS API 回傳 `HTTP 403` | 向 NODASS/相關管理單位確認是否需登入、授權或改用資料下載。 |
| `GOCI_SSH` | NODASS API 回傳 `HTTP 404` | 確認 API 代碼是否更名、資料是否下架，或改用其他海面高度/潮位資料。 |
| `OBS_DATA` 大量歷史觀測值 | 單站端點可讀，但大量使用需確認限制 | 若要批次抓取所有站點 72 小時事件窗，建議確認流量限制與授權。 |
| 格網流場資料 | 尚未接入 | 若要做 OpenDrift/OceanParcels 粒子追蹤，需取得 HYCOM、ROMS、POM 或等價流場資料。 |
| 水利署 FHY API Key | 尚未提供 | 用於河川水位、流量、流域與入海口條件。 |
| 歷史污染事件/稽查紀錄 | 尚未取得 | 用於因果推論與模型驗證。 |

## 論文方法復現狀態

| 方法 | 系統內已復現內容 | 下一步 |
| --- | --- | --- |
| 多測站時空貝氏異常偵測 | 事件節點、鄰近測站、72 小時窗、方向可達條件 | 建立正式 Bayesian Network 條件機率表。 |
| 水動力 + Bayesian/MCMC 污染源反推 | 平均流速、流向、風向、距離與污染物吻合度排序 | 接入格網流場後改為後驗機率排序。 |
| 主動式污染源追蹤 Agent | 異常後自動列候選來源、資料狀態與下一步需求 | 加入不確定度與下一採樣點推薦。 |
| 衛星葉綠素/懸浮物影像比對 | NODASS CHL、TSM、SST 影像端點探測 | 依事件日期自動抓取 ±72 小時影像並比對測站周邊像素。 |
