# 2026-09-12 推薦功能升級匯報

## 本次開始實作的功能

| 功能 | 已完成內容 | 對系統的價值 |
| --- | --- | --- |
| 事件窗影像佐證 | 新增「影像佐證」頁，依事件污染群組自動推薦 NODASS 影像/API 入口。 | 讓衛星葉綠素、懸浮物、海溫與自然色圖磚可以進入事件判讀流程。 |
| 下一採樣點推薦 | 新增「採樣建議」頁，產生異常測站複測點與候選來源至事件測站的斷面採樣點。 | 讓系統不只回報來源排序，也能提出下一步現地調查位置。 |
| 來源證據拆解 | 來源追蹤頁新增分數拆解，顯示綜合分數、上游流向、上風方向、污染物吻合與 72 小時可達性。 | 讓來源推估更透明，方便人工審查與後續模型校正。 |
| 採樣點互動地圖 | 採樣建議頁已用 Leaflet 顯示推薦點位。 | 讓現地採樣人員可直接查看點位分布與經緯度。 |

## 已符合的時空一致性

1. 影像佐證固定使用異常事件日前後 72 小時。
2. 來源排序仍保留上游、上風與 72 小時可達條件。
3. 採樣點由候選來源與異常測站之間的傳輸關係產生，不任意加入無關區域。
4. 採樣策略先複測異常測站，再沿最高順位候選來源與事件測站布設斷面點。
