# 論文與專案功能評估

本文件整理 NODASS 海岸污染來源追蹤 AI 第一版可立即復現的研究功能，以及需要後續資料/API 支撐的升級方向。

## 已復現至系統的新功能

| 功能 | 來源依據 | 系統實作 |
| --- | --- | --- |
| 多測站時空一致性 | 多測站時空貝氏網路異常偵測研究 | 已在來源排序前篩除不符合 72 小時、上風或流向可達的候選來源 |
| 水動力污染源反推雛形 | 水動力 + Bayesian/MCMC 污染源反推研究 | 已用平均流速、距離、方向角與污染物吻合度產生來源排序 |
| 主動式污染源追蹤 Agent 雛形 | 不確定性感知的海洋污染源追蹤 Agent 研究 | 已由異常事件自動推估來源、資料缺口與下一步 API 需求 |
| 衛星影像輔助判讀 | NODASS Sentinel/GOCI 葉綠素與懸浮物資料 | 已新增 NODASS API 清單，將 CHL、TSM、SST、SSH 標為可申請資料 |
| 正式放流口候選來源 | 環境部 EMS_S_03 水污染源許可及申報資料 | 已將環境部放流口轉成來源候選點，納入來源排序 |

## 尚未完全復現的功能

| 功能 | 缺少資料 | 後續作法 |
| --- | --- | --- |
| 後驗機率式污染源排序 | 長期排放量、流場格網、歷史事件標籤 | 以 Bayesian Network 或 Bayesian-MCMC 取代規則分數 |
| 粒子漂流模擬 | HYCOM/ROMS/POM 流場、風場、潮位格網 | 接 OpenDrift 或 OceanParcels |
| 因果推論 | 排放量、降雨、流量、稽查、上游站時序 | 建立事件前後處置/暴露變數與對照區 |
| 下一採樣點推薦 | 即時風流場、現場採樣成本、船舶/無人載具位置 | 加入不確定度與資訊增益 |

## NODASS API 申請優先順序

1. `OBS_DATA`：觀測站即時/歷史監測值，支援風、流、潮、浪與海溫。
2. `CWA`、`IHMT`、`WRA`、`NAMR`：觀測站 metadata，支援測站距離與鄰近站篩選。
3. `GOCI_CHL`、`Sentinel2_CHL`、`OLNT_S3_CHL`：葉綠素 a 影像，支援優養化與藻華判讀。
4. `GOCI_TSS`、`Sentinel2_TSM`、`OLNT_S3_TSM`：懸浮固體影像，支援河口泥沙與污染羽流。
5. `SLNT_S3_SST`、`TFRIN_SST`、`CMEMS_SSH`：海溫與海面高度，支援水團、潮汐與生態壓力判讀。
6. `EPA/MWQ`、`TFRIN/MWQ`：海水水質站，支援官方水質背景補齊。
7. `OCA/NPMPA`、`EPA_ORGANISM`：敏感受體與生態調查，用於風險優先序。
