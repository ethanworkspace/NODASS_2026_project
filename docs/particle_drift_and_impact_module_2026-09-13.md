# 粒子漂流、海流風向與汙染影響模組更新報告

更新日期：2026-09-13

## 本次新增功能

### 1. 粒子漂流顯示

地圖新增「粒子漂流」圖層，用多個粒子呈現汙染水團在 72 小時事件窗內的可能移動方式。

- 粒子沿著 72 小時擴散軌跡漂移。
- 粒子會加入橫向展寬，表示汙染水團不是單一路徑，而是會隨時間擴散。
- 粒子動畫會在地圖上持續更新，可作為擴散方向與採樣斷面的視覺參考。

### 2. 海流與風向圖層

地圖新增「海流與風向」圖層。

- 海流以主導流向呈現，使用事件窗內海氣象資料。
- 風向以主導風向呈現，作為汙染漂移方向的輔助判斷。
- 地圖圖層可開關，方便單獨查看擴散軌跡、粒子、海流、風向與受影響區域。

### 3. 汙染擴散可能造成的影響模組

新增「汙染擴散可能造成的影響」模組，依污染物類型與可能受影響點位，整理五類影響：

- 生態影響
- 漁業與養殖
- 遊憩與海岸使用
- 取排水設施
- 監測行動

每個影響模組會以高、中、低風險呈現，協助判斷巡查與採樣優先順序。

## 模型邏輯

目前粒子漂流仍屬初版方向性模型：

1. 以事件測站作為粒子起點。
2. 使用事件日前後 72 小時的平均流速估算漂移距離。
3. 使用主導海流方向作為主要漂移方向。
4. 使用主導風向輔助判斷汙染水團偏移方向。
5. 以橫向展寬表示汙染水團擴散。
6. 將粒子軌跡與沿岸參考點比對，產出可能受影響區域。

## 時空一致性

本次更新仍符合 72 小時時空一致性：

- 粒子漂流只使用事件窗內資料。
- 海流與風向只取事件窗主導值。
- 擴散軌跡只輸出 0 到 72 小時。
- 受影響區域由 72 小時軌跡比對而來。

## 目前限制

- 粒子漂流為展示用方向性模擬，尚未接入正式格網海流。
- 尚未輸出粒子濃度場或污染濃度等值線。
- 尚未接入保護區、養殖區、海水浴場、取水口等完整受體資料。
- 若要作為正式預警，建議接入 HYCOM、ROMS、FVCOM、NODASS 或其他海流格網資料。

## 建議下一步

1. 接入格網海流資料，讓每個粒子依時間與位置取得不同流速流向。
2. 增加粒子濃度熱區圖或 GeoJSON 輸出。
3. 接入養殖區、保護區、海水浴場、取水口與港區敏感受體。
4. 增加不同風場情境的比較模式。
5. 加入粒子抵達時間，用來排序應變與巡查優先順序。
