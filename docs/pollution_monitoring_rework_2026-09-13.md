# 台灣海岸污染監測系統改版匯報

更新日期：2026-09-13

## 本次處理摘要

本次已先將系統還原到上一版基礎，再把專案定位由「海岸污染來源追蹤」改為「台灣海岸污染監測系統」。新版系統重點改為：

- 監測海岸是否發生污染事件。
- 若發生污染，依 72 小時事件窗預測污染可能擴散方向與範圍。
- 列出可能受影響的沿岸參考點。
- 保留 NODASS 影像佐證、採樣建議、時空一致性與論文方法復現頁。

## 已完成更新

### 1. 系統名稱與介面改版

- 網頁標題改為「台灣海岸污染監測系統」。
- 主畫面改為「台灣海岸污染監測與擴散預測」。
- 導覽頁籤改為「污染事件」與「擴散預測」。
- 統計卡片改為污染事件、沿岸參考點與擴散判斷。

### 2. 污染擴散預測

新增 72 小時擴散軌跡模型：

- 使用事件窗內主導流向作為主要方向。
- 加入主導風向作為輔助方向。
- 使用平均流速估算 12、24、36、48、60、72 小時後的位置。
- 輸出每個時間點的緯度、經度、方向與累積距離。

目前模型是透明規則式初版，適合展示、決策輔助與資料需求盤點；若要正式應用，後續應接入格網海流與粒子漂流模型。

### 3. 可能受影響區域

系統會將擴散軌跡與沿岸參考點比對，依最近距離給出風險等級：

- 高：距離擴散軌跡 8 km 內。
- 中：距離擴散軌跡 18 km 內。
- 低：距離擴散軌跡 35 km 內。
- 超出 35 km 不列入優先清單。

### 4. 地圖完整顯示

- 使用 Leaflet + OpenStreetMap 作為互動式地圖。
- 地圖顯示污染事件點、72 小時擴散軌跡、可能受影響區域。
- 可縮放、平移、點選圖層與查看 popup。
- 若外部地圖服務或 CDN 無法載入，會切換到內建台灣海岸示意圖。

### 5. 時空一致性

新版仍保留「事件日前後 72 小時」規則：

- 擴散預測只使用事件窗內海氣象資料。
- 事件窗外資料不納入判斷。
- 影像查詢也依事件日前後 72 小時產生。
- 採樣建議以污染測站複測與預測擴散方向為主。

### 6. 論文可復現功能

已放入系統畫面與功能中的文獻概念：

- 多測站時空異常偵測。
- 水動力污染傳輸概念。
- Bayesian/MCMC 污染推估概念。
- 主動式採樣策略。
- 衛星 CHL/TSM/SST 事件窗佐證。

目前復現方式以可解釋規則、地圖軌跡與資料節點呈現；下一階段可將模型升級為正式後驗機率或粒子漂流。

## 仍需自行申請或確認的 API / 資料

| 名稱 | 用途 | 狀態 |
| --- | --- | --- |
| 中央氣象署開放資料 API | 雨量、風、潮位、海象 | 已有授權碼，可持續串接 |
| 環境部資料開放 API | 水污染源、放流口與水質資料 | 已有授權碼，可持續串接 |
| 水利署 FHY API | 河川流域、水位、流量、河口輸入 | 仍需水利署 API key |
| NODASS API 服務 | 海洋觀測站、影像與圖磚 | 多數 noapi 可讀；正式 API 權限仍建議申請 |
| NODASS EPA/MWQ | 海域水質觀測站資料 | 目前需確認權限 |
| Google Earth Engine | 衛星影像、雲遮處理、長期時序分析 | 需自行申請並設定服務帳戶 |
| 格網海流資料 | 正式漂流與濃度擴散模擬 | 需確認資料來源與格式 |

## 目前限制

- 目前為初版方向性擴散預測，不輸出正式污染濃度場。
- 尚未接入完整海流格網，因此不能取代正式海洋數值模式。
- NODASS 影像目前以 API 入口和事件窗佐證為主，尚未直接疊加到 Leaflet 圖層。
- 系統不自動補齊缺漏資料；缺資料僅整理成清單供後續申請與匯入。

## 建議下一步

1. 申請或確認 NODASS 正式 API 權限。
2. 補齊水利署 FHY API key。
3. 決定是否使用 Google Earth Engine 做衛星影像時序與雲遮處理。
4. 導入格網海流資料後，將目前 72 小時線性軌跡升級為粒子漂流模擬。
5. 將污染擴散風險輸出成 GeoJSON，提供 GIS 或其他平台使用。
