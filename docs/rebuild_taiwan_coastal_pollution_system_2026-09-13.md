# 台灣海岸汙染監測系統重新製作匯報

更新日期：2026-09-13

## 重新製作目標

本次將原本偏向 NODASS 與汙染來源追蹤的展示系統，重新製作為「台灣海岸汙染監測系統」。新版系統聚焦三個問題：

- 海岸是否發生汙染。
- 發生的是哪一類汙染物異常。
- 若發生汙染，未來 72 小時可能擴散到哪裡。

## 新版系統頁面

### 1. 監測總覽

- 第一屏直接顯示目前選取事件、汙染物、汙染狀態、72 小時擴散距離與可能受影響區域數量。
- 顯示台灣海岸互動地圖，包含汙染事件點、擴散軌跡與可能受影響區域。
- 提供高風險汙染事件清單，可點選切換事件。

### 2. 汙染事件

- 可搜尋事件、測站與汙染物。
- 可依汙染群組篩選葉綠素、營養鹽、懸浮固體與重金屬。
- 每筆事件保留實測值、基準值與異常分數，方便判斷汙染程度。

### 3. 擴散預測

- 使用事件日前後 72 小時內的主導流向、主導風向與平均流速。
- 以 12 小時為間距輸出擴散軌跡。
- 列出可能受影響區域，依軌跡最近距離分成高、中、低風險。
- 地圖可縮放、平移與點選圖層。

### 4. 影像與資料

- 依汙染物類型自動列出 NODASS 事件窗影像或圖磚 API。
- 系統不自動補齊缺漏資料。
- 若資料不足，僅列入資料需求與待申請清單。

### 5. 應變建議

- 建議先做異常測站複測。
- 接著沿預測擴散方向布設採樣斷面。
- 優先巡查高風險受影響區域。

### 6. 系統說明

- 說明資料層、監測層、預測層與決策層。
- 列出仍需申請或確認的 API。
- 保留論文可復現功能對應關係。

## 時空一致性落實方式

新版系統延續並強化 72 小時時空一致性：

- 汙染事件發生後，只使用事件日前後 72 小時內的海氣象資料。
- 擴散方向以事件窗主導流向為主，主導風向為輔。
- 預測軌跡只輸出 0 到 72 小時範圍。
- 影像查詢時間窗同步使用事件日前後 72 小時。
- 事件窗外資料不納入判斷，避免混用不同水文條件。

## 擴散預測邏輯

目前初版使用透明可檢核的方向性模型：

1. 讀取汙染事件測站經緯度。
2. 讀取事件窗主導流向、主導風向與平均流速。
3. 以主導流向 72% 與主導風向 28% 進行方向混合。
4. 用平均流速估算 12、24、36、48、60、72 小時後的位置。
5. 將預測軌跡與沿岸參考點比對。
6. 依距離給出可能受影響區域。

## 仍需申請或確認的資料

| 名稱 | 用途 | 狀態 |
| --- | --- | --- |
| 水利署 FHY API | 河川流量、水位、流域與河口輸入 | 仍需 API key |
| NODASS 正式 API 權限 | 海洋觀測、影像、圖磚與正式服務 | 建議申請 |
| NODASS EPA/MWQ 權限 | 海域水質測站資料 | 需確認權限 |
| Google Earth Engine | 衛星長期時序、雲遮處理與格網影像 | 需自行申請 |
| 格網海流資料 | 正式粒子漂流與濃度場模擬 | 需決定資料源 |

## 目前限制

- 目前是初版方向性擴散模型，不是正式海洋數值模式。
- 尚未輸出汙染濃度場。
- 尚未直接疊加 NODASS 影像圖層到 Leaflet 地圖。
- 缺漏資料不會自動補齊，只會在系統與文件中列出。

## 建議下一階段

1. 接入格網海流資料，將線性軌跡升級為粒子漂流。
2. 將 NODASS 圖磚疊加到互動地圖。
3. 輸出 GeoJSON，提供 GIS 平台使用。
4. 增加事件比較功能，查看同一海岸不同日期的汙染擴散差異。
5. 將規則式風險分數升級為貝氏後驗機率。
